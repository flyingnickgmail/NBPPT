# Source-first image presentation

1. Read the whole source. Identify audience, argument order, evidence, exclusions,
   uncertain claims and future plans. Never replace it with generic business copy.
2. Read the selected customer's style reference. Existing template files are visual
   references, not finished slides to repeat or fill cyclically. If unavailable,
   use the supplied palette and description and disclose the missing reference.
   Never claim to inspect unavailable source attachments or invent logos.
3. Write the required deck plan. Every page must advance a different argument and
   retain source evidence and caveats. Choose charts for counts, diagrams for
   relationships, comparison for alternatives, swimlanes for responsibilities,
   and timelines for sequences. Mix suitable layouts under one visual identity.
   Do not force every page into cards plus a bottom arrow. Do not pad page count.
4. Use built-in image_gen for each page, with exact Chinese text and minimal dense
   prose. Keep 16:9, legible titles and labels, restrained brand colors, whitespace,
   and consistent typography. Never turn unsupported data into facts or ROI.
5. Copy only each tool-returned image path to the current job's numbered assets.
   Global recent-image scans can mix unrelated jobs and are forbidden.
6. Visually inspect every page. Repair wrong characters, missing caveats, wrong
   numbers and repeated content. Record reviewed pages and unresolved issues.
   Missing images, tool failures and unresolved defects mean failure, not completion.

The worker owns final packaging. Do not create synthetic PNGs or template-rendered
slides as a fallback, and do not deploy, send messages or access unrelated data.
