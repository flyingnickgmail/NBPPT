# Commercial PPTX Generation & Beautification Skill (`pptx-pro`)

When invoked, follow these steps to build a widescreen (`13.333` x `7.5` in) presentation from `./task_spec.json`:

1. **Generate Visual Assets First**:
   Ensure `./output/assets` contains the high-DPI charts generated by `codex-visual`.
2. **Build Presentation Deck**:
   Run the master deck builder script:
   ```bash
   python3 /Users/flyignick/Code/person-work/worker/agent_skills/.claude/skills/pptx-pro/scripts/build_deck.py \
     --spec ./task_spec.json \
     --assets ./output/assets \
     --out ./output/presentation.pptx
   ```
3. **Typography Rules**:
   - Every text run (`run.font.name`) is explicitly bound to `"PingFang SC"` / `"Noto Sans CJK SC"` so Simplified Chinese characters render cleanly across macOS, Windows, and Linux.
   - Slide previews (`slide_preview_1.png`, etc.) are automatically exported to `./output/assets/` for instant browser preview.
