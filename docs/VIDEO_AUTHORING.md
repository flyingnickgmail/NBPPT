# 内容优先的视频制作

> **入口与现行参数**统一见 [当前视频能力](VIDEO_CAPABILITIES.md)。本页保留实现细节及 P0–P6 的分阶段记录；带日期的测试结果、旧限制和候选说明属于对应版本，不应当作当前运行能力。

本文描述基于代码基线 `edd11b4`、在工作分支 `codex/voice-video-story` 实现并本地验收的视频能力，不代表已推送或部署到生产环境。服务器依赖、资源容量及在线客户端验收仍需另行完成。

## 产品链路

用户录音或上传音频 → 服务器离线转写 → 用户核对编辑文字 → 创建视频任务 → Claude 内容逻辑及口播 → 校验 → 可选微软自然配音与实测时长分配 → Claude 故事分镜 → 校验 → 受审实景剪辑或原生横/竖屏动画 → 复用配音与字幕 → 文件、音轨和稿件一致性验收 → 原子发布 → 结算。

转写本身不创建视频任务、不冻结视频算力；转写内容必须由用户确认。临时音频在请求结束或失败后删除。当前录音限制为 3 分钟 / 10 MB，单进程串行转写，同一用户最短 20 秒间隔。应用既有单网关锁仍生效；离线模型加载需要单独验收服务器容量。

微软配音先按自然语速生成并缓存，由程序在总时长内分配每段镜头秒数，再交给 Claude 编排分镜。最终合成复用同一份音频，避免二次请求出现不同读法；时长确实不足时失败并退款。离线配音仍沿用既有路径。

Claude 两个步骤均无工具、无 MCP、无会话持久化，不执行模型生成的代码。使用与 PPT 相同的规范登录、账号租约、限流和熔断。账号租约只包住模型调用，配音和渲染不占用 Claude 租约；配音准备另有限制并发的资源闸门。每个产品 key 的 Claude 权限仍在冻结前检查，产品历史和额度仍按租户隔离。内容契约不通过时，限剩余预算最多修订一次；认证、限流、额度错误不触发该修订。

内容稿保存论点、因果链、完整论证、事实/推论边界、口播及字幕。模型通过编号选取原文证据，由程序绑定原文字符，避免中文标点被模型重打而改变。分镜不得更改已通过检查的口播、时长、顺序和原文依据。数字、重复内容、承诺边界及未知字段均有严格校验；这些检查不等于语义事实核验。

动画采用受信的 Python/Pillow + FFmpeg 渲染，不引入模型代码执行、Remotion 或即梦付费调用。支持 8 类对象与流程镜头、5 类主体图形和独立竖屏排版。解释动画保留兼容路径；实景模式通过已审核素材库或无密钥公开搜索取得素材，由 Claude 在实际可用窗口内编排短镜头，受信 FFmpeg 剪辑。

## 使用入口

网页选择「视频」或「PPT＋视频」后，在创作表单中直接设置「是否配音」与「配音音色」，不必展开高级设置。服务器启用微软配音后显示云希男声和晓晓女声，并默认选择云希；两种音色可用同一段通用口播试听，也可关闭配音生成静音视频。选择随下一次生成任务生效，试听不替换已有成片，不创建任务或扣点。试听文件及生成说明位于 `gateway/static/voice-samples/`。

展开「风格与输出设置」，在「视频制作方式」中选择「Claude · 内容、口播与镜头制作」。配置了实景来源后，可在「画面方式」中选择「实景故事剪辑 · Claude」；「解释动画」保留独立路径。Claude 入口仍受当前密钥的权限与账号运行状态约束，未配置的能力不会因本地文档或试听文件而自动启用。

HTTP：`POST /api/jobs`，`task_type=video`、`execution_mode=claude_cli`。MCP 的 `create_video` 同样新增 `execution_mode=claude_cli`。实景设置为 HTTP `video_visual_mode=live_action` / MCP `visual_mode=live_action`。Claude 支持 6–180 秒；旧客户端的 auto / Codex 路径仍限60秒，不隐式切换模型。

产物通过原有认证下载：`content_manuscript.md`、`manuscript.json`、`narration.txt`、`storyboard.json`、`assets/storyboard.png`、`subtitles.vtt` 和实际 MP4。客户端新增内容稿、口播稿和分镜下载；退出账户会清除私有预览与转写状态，迟到的转写不会填入另一账户草稿。

## 运行配置

- 沿用 `NBPPT_CLAUDE_ENABLED`、`NBPPT_CLAUDE_OWNER_USER_ID`、`NBPPT_CLAUDE_HOME`、`NBPPT_ACCOUNT_STATE_DIR`；不复制凭据。
- 可选微软在线声音：安装 `requirements-microsoft-voice.txt`，验收后在网关和 Worker 设置 `NBPPT_MICROSOFT_EDGE_ENABLED=true`。这是 edge-tts 适配器，不是 Azure Speech SDK。
- 离线转写：预先安装 whisper.cpp 和兼容的本地模型，配置 `NBPPT_ASR_BIN`、`NBPPT_ASR_MODEL`，可指定 `NBPPT_ASR_WORK_DIR`。运行时不下载模型。不要直接把本机的 1.6GB 模型照搬到小内存 VPS。
- 保留现有 FFmpeg、ffprobe、中文字体、Python 依赖与字幕滤镜要求。视频渲染增加独立单任务资源闸门，释放 Claude 租约后再渲染。
- 新故事视频配音使用两遍响度校准，并在最终 AAC 和字幕编码后检查：-17 至 -15 LUFS，真峰值不高于 -1.5 dBFS。在线语音不加速、不截断；不合格则失败退款。

## 复现实验

先运行 `python -m pytest -q -ra` 和 `node --test tests/*.cjs`。2026-10-23 的本地回归为后端359项通过、6项跳过，前端45项通过。跳过项需要未配置的可选 MeloTTS/Kokoro 离线模型，不计为通过；本轮回归未重新请求外部模型、语音或素材服务。

同次检查用当前交付校验器复检既有180秒实景成片及10份交付文件，文件摘要、完整解码、稿件、音轨与素材来源检查通过；两份微软试听也通过声音门槛。文件状态通过不等于内容或审美获认可，内容状态仍为 `NOT_REVIEWED`（待人工审阅）。

实际验收脚本 `tools/video_acceptance.py` 需要操作者显式提供已有授权 SSH 控制连接，仅在服务器执行无工具文字推理；本地使用独立 SQLite 数据库、真实网关/Worker 代码及环回 HTTP 流渲染，绝不调用生产产品钱包。脚本不属于普通离线回归，执行时会使用已有账户的模型额度，不能将旧成片复检当作一次新的联网生成验收。

`--retry-failed` 只在操作者明确重跑验收时使用，复用原稿参数并通过产品重试接口创建新任务；不会复活原失败任务。模型认证失败时必须先处理账号，禁止用该参数绕过熔断。

## 实景故事模式

- `NBPPT_SCENE_SOURCE=catalog` 与绝对路径 `NBPPT_SCENE_CATALOG`：使用已审核且摘要一致的授权素材。素材文件独立于仓库和用户输入，不把本机路径提供给客户端。
- `NBPPT_SCENE_SOURCE=search`：复用公开素材搜索、原文语义筛选、逐秒抽帧和实际横竖屏构图审核。`NBPPT_SCENE_SEARCH_PROVIDER=mixkit` 或 `commons` 不需要密钥；网页结构/授权变化会失败，不回退静态图。
- Claude 口播与分镜仍无工具。搜索视觉审核沿用受限任务输入的 Codex 规划执行器，单次有上限、失败不自动重试、不允许代理委派。此检索调用成本尚沿用旧路径估算，未证明搜索模式生产收费覆盖真实模型消耗。
- 只接受编号/秒数/选镜原因；不接受模型路径、网址或滤镜。每镜2–6秒、非重叠时间窗、不同景别；同素材不能连续三个镜头；实景至少60%，解释动画最多40%。这些是底线，不是审美合格证。
- 新增 `footage_sources.json` 与 `footage_credits.html`，网关独立验证来源、引用、镜头时长、审核覆盖与署名后才结算。带“情境演绎”角标，素材不是真实客户事件或人物背书。实景配音片加入本项目合成的轻量器乐底乐，按实际语音能量压低，最后对混音重新测量响度。
- 三分钟任务预算按时长有界增加，最多3美元规划上限；共用已有账号锁和熔断。无部署、无付费生视频/音乐服务。
- 本轮180秒验收使用已审旧素材与本轮公开检索补充的素材库，完整分镜与时间线由真实 Claude 任务生成；不等同于已验证所有行业均能自动搜满三分钟。搜索路径仍须按输入具体审核素材覆盖。
