# 本地权限与交付修复

本次实现只保证文件层面的交付完整性，不证明文字、数据、结论或视觉质量正确。
没有部署或修改线上数据库。旧任务和原始生成内容没有批量迁移。

## 启动前配置

复制 `.env.example` 为本地 `.env`。分别生成两个至少 32 字符的随机值，填入
`NBPPT_ADMIN_API_KEY` 和 `OVERSEAS_WORKER_SECRET`。不要重复使用演示密钥。
首次启动会创建管理员；已有 founder 账户会保留余额并获得管理员身份，公开演示密钥会停用。
生产浏览器使用 HTTPS，设置 `NBPPT_PUBLIC_ORIGIN` 为准确的访问来源。
只有本机 HTTP 调试才设置 `NBPPT_COOKIE_SECURE=false`，测试结束恢复默认值。
浏览器登录使用访问密钥兑换 8 小时的 HttpOnly 会话；MCP 使用 Authorization 请求头。
密钥撤销立即使关联会话失效。当前凭据表仍保留旧式明文存储，数据库必须按秘密文件保护。

生产代理必须正确传递协议与 Host，并只信任实际代理地址；后端端口不得绕过 HTTPS 入口公开。
仓库启动脚本和容器端口已收紧，但已有服务器的 systemd 和网络规则不会自动改变。

## 支持的运行边界

- 一个 SQLite 数据库只允许一个网关进程，启动锁会拒绝第二个进程。
- 网关与执行节点必须共享 `workspace/jobs` 文件系统。远程分离且不共享存储时无法结算成功。
- 网关重启后，遗留 RUNNING 任务标记失败并仅退款一次；不自动恢复生成或重复扣款。
- 浏览器断开会取消当前请求并退款。执行进程组在取消/超时时清理，硬断电后的进程由操作系统处理。
- 执行节点拒绝复用任务编号，先写入 `staging`，检查完成后将目录重命名为 `output`。
- 产物以交付清单和 SHA-256 校验值发布；下载按归属和清单检查，未结算及被修改的产物不提供下载。
- 原有无清单任务不会被自动认定合格，下载会拒绝；后续需独立复核和迁移，不能伪造清单放行。
- Codex 需将本任务生成图片显式复制到 `staging/assets/slide_preview_N.png`；不再扫描全局图片目录。
- PPT 必须有可解析的宽屏 PPTX、连续编号的 1672×941 PNG 和对应网页。缺页、额外页、错尺寸均失败。
- 仅视频任务无需 PPT；视频要求 ffprobe 可解析，存在视频流并满足约定时长和比例。组合任务两者都检查。
- 网页演示使用嵌入图片和浏览器沙盒，允许翻页脚本但不允许访问工作台身份、表单提交或网络调用。

## 本地验证

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q tests/test_security_delivery.py
```

测试使用临时数据库和人工生成的文件，不调用线上服务或付费模型。真实视频测试需要 ffmpeg/ffprobe；缺少时明确跳过。
旧的 `test_e2e_platform.py` 是会创建真实任务的手工集成脚本，本轮不执行。

尚未覆盖真实 Codex/Claude 模型生成、文字识别、内容终审、Linux 的 PPTX 渲染依赖修复、生产 HTTPS/防火墙验收。
执行器仍具有较高的宿主权限；权限修复不能替代操作系统隔离。上线前需要独立处理专用低权限执行用户和账号目录访问。
