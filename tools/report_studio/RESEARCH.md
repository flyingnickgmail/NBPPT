## 从网页直接确认的事实

两份报告都是完整 HTML 网页，而非 PDF 动画或 PPT 视频。浏览器可见大字号中文叙事封面、正文长页、章节跳转、嵌入图表、数据下钻以及来源登记册。第一份有三态封面；第二份提供四态封面与更多图表类型。

直接读取 HTML 可见：`css/fonts.css`、`css/style.css`，`vendor/d3.min.js`，`js/data.js`，共享 `utils.js`，独立 `chart-*.js`，封面 `cover*.js`，以及 Kimi 发布 SDK。第二份还引用 `topojson-client.min.js`。这些证据说明产物采用模块化前端结构；并不能证明生成时用了特定模型或固定模板。

读取第一份 `utils.js`、`main.js`、`cover.js` 可以确认：

- Canvas(网页画布)配合三维投影函数与 `requestAnimationFrame`，形成动态封面；无需由此推断使用了 WebGL 或 Three.js。
- D3(数据可视化库)依赖存在，图表按主题拆分脚本。
- 数据点点击弹出下钻卡，来源按钮查找 `SRC` 来源数组；正文与来源使用锚点编号连接。
- `IntersectionObserver` 监听章节进入视口，触发淡入。
- `prefers-reduced-motion` 为减少动画的系统偏好提供替代呈现。
- 发布 SDK 中启用了统计参数和水印参数。其内部部署服务、访问日志与生成流水线不公开。

本地只保留研究用下载证据，不把示例的财务数字当作已核验事实。本轮研究对象是网页能力与表现方式，并未核查其长城汽车分析。

## 官方说明与推断的边界

[Kimi 深度研究官方说明](https://www.kimi.com/help/deep-research/deep-research-overview)称产品会规划、搜索、推理、调用工具，并交付带来源的长文与可交互的可视化报告；支持 HTML 预览、源码复制和公开链接分享。

合理推断的通用流水线是：研究材料 / 用户正文 → 叙事策划 → 数据及证据整理 → 网页与图表生成 → 浏览器检查 → 发布。但网页本身不能证明 Kimi 内部每一步的模型、提示词、重试机制、模板占比或成本，不能宣称已逆向得到内部算法。

## 为什么会显得专业

视觉表现：少量强调色、大字号标题、正文可读宽度、充分留白、统一来源脚注，形成稳定的阅读节奏。动效集中在封面与入场，不要求整页持续运动。

信息设计：先提出一个判断，再给证据；每张图回答一个问题。长城示例为特定主题设计汽车部件挂载指标、财务比较、风险敞口、路线图等隐喻。漂亮的图并不额外证明论点成立。

交互：目录负责导航；图表负责概览；下钻负责解释；来源册负责追溯。读者可以先扫整体，再查某个数字。

## 本轮推荐实现

保留项目现有 Python 运行环境，把工具隔离在 `tools/report_studio`。模型只生成受约束的 JSON(结构化内容)，组件负责最终网页。这样可以在每次输出中统一处理字体、配色、屏幕尺寸、打印、证据和输入转义，避免模型任意写代码导致页面不稳定或执行外来脚本。

首版以条形、趋势、流程和叙事章节覆盖通用报告。图表单位、点值、引文由模型提供并做基础检查。原文完整保留，供用户对照。导出 HTML 内嵌样式、脚本与数据，无远程图表库、字体、统计或 Kimi 水印依赖。

代价是主题自由度受到组件限制。要达到示例的全部定制能力，需要增加主题图形组件，或另建“模型编写网页代码 → 隔离预览 → 自动检查 → 修复”的生成模式；后者维护与安全成本更高，不能将首版称为完整复刻。

当前工具解决“已有内容转美观交互报告”。自动研究事实、接入文件解析、内容编辑、多模型、多用户与公开发布均不属于已实现能力。

## 第二版实际扩展

按用户后续要求，已增加单节多图、可排序矩阵、现状/建议目标、分版本时间路线和汽车主题组件。数字、逐字引文、来源与时间精度先检查，失败时由同一模型局部修复指定字段，再交给固定组件排版。缺月折线断开，全年任务不伪装为半年任务，无直链来源明确标注。以同一份长城输入的实际生成与浏览器对照为证据，见 [第二版实测](../../workspace/kimi-research/v2/COMPARISON.md)。

这些扩展补上首版主要的信息设计空缺，仍不等于原作的全部定制表现。全球地图、散点、天平和上下文侧栏尚未实现，封面目前为二维汽车矢量图的分层变换。

## 第三版与能力复用

地图、散点、可比口径着色和章节上下文已实现；路线支持紧凑与泳道切换。新增长材料内容复审，审查重要分析链、遗漏与过强结论，并有限度补图；正文数字、来源绑定和表达覆盖的结果检查进入工作台与命令产物。不是为某家公司新增硬编码数值。

统一入口包含生成、已有初稿复审、结构化内容重排和严格检查，见 [能力说明](CAPABILITY.md)；实际失败、误报修正、续跑与最终浏览器验收见 [第三版实测](../../workspace/kimi-research/v3/COMPARISON.md)。当前仍缺少原作的证据天平、分层架构和更丰富的封面图形；模型与规则均不能保证下一份材料的事实真实性或审美质量。
