原理与使用

让内容、图形与证据一起工作。

输入材料 → 编排分析与图形 → 检查引文、数值和时间 → 长材料内容复审 → 统一组件排版 → 导出离线网页。下一份材料也执行同样流程，无须另写页面。

下次怎么用

  1. 粘贴正文或导入 TXT / Markdown(带标题和列表的文本)。材料开头说明给谁看、要回答什么问题；保留数字的时间、单位、口径及来源。
  2. 选择智能编排并生成。Codex(内容生成工具)使用现有账户额度；本地排版保留原文，不调用模型。
  3. 查看质量检查中的待核对项，检查正文、图表、引句和来源。长材料还会复审遗漏、过强结论和表达覆盖，必要时局部修改或补图。
  4. 下载网页离线阅读，保存内容以便重新导入或改版。打印支持浏览器存为 PDF(便携文档)。刷新前请保存需要保留的内容。

可复用的表达组件

  • 前后观察：同一对时期、统一单位和尺度，各端点分别查原文；不把实际与目标混用。
  • 同业矩阵：排序、逐格引文；明确方向与可比口径后才着色，不做综合排名。
  • 目标对比：每行独立尺度；建议目标与已实现结果分开，缺失现状不填零。
  • 时间路线：分类泳道与紧凑时间线可切换，保留原文时间精度、版本与责任。
  • 双变量散点：同时展示两个原始值，点选或从明细列表查证据。
  • 全球市场图：离线陆地轮廓、等大国家节点与市场证据；不是精确厂址或销量大小图。
  • 汽车主题：原创轮廓、分层、线框与可点击经营指标。
  • 条形、趋势、流程、多图布局；宽屏侧栏跟随章节显示本节数据，手机回归单栏。

生成后怎样判断

工具检查引句、数值出现、正负号、来源编号与时间精度，也提示正文数值、来源绑定和表达覆盖问题。内容复审读取完整图表，可局部改写、补图或修正具体选图问题；新增和替换图均重新检查引文，不能改来源、封面指标或删章节。通过这些检查不等于事实已经真实、单位可比、分析成立；图数和章节数也不是质量评分。

能力边界

演示材料是虚构样本。当前不自动联网研究、不解析 PDF 或 Word(文字文档)、不创建公开链接。地图仅支持俄罗斯、巴西、泰国、澳大利亚、南非与中国；未知国家不凭空定位。证据天平、分层架构及更自由的主题图尚未实现。跨主题稳定性仍需更多真实样本验证。
