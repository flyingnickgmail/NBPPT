# 先审题，再选图

先说明正常业务怎样运行，再问哪里偏离常态。统计对象、交易层级、分母或时间不同所产生的差异，不是自动成立的经营问题；不要把常识写成惊人发现。

模型必须给出：读者要作的具体决策、正常业务基线、材料支持的异常或不确定性、支持证据、替代解释、缺失的判别数据，以及会改变行动的发现。问题若只在复述定义，重新选题；材料不足以确认异常时，改为可检验的问题，不能预设恶化已经发生。

区分三层：观测事实、来源作者判断、本报告建议。即便数字及引文完全正确，结论仍可能不成立。比较两个增速不能计算库存、转化率、因果或损失；累计流量差额不能自动当作期末库存。推断异常须有同口径的正常范围/历史基线、业务状态和替代解释；没有就明确未知，不造阈值。

渠道经营例：经销模式中，批发/出口与终端销售属于不同环节，渠道备货及合理在途是正常经营的一部分。真正有价值的问题是库存与需求、补货周期是否匹配，周转/库龄/成交价格及资金占用是否相对基线恶化。新市场铺货、季节性、运输与统计滞后均可能解释差额，不能默认全部是滞销。不同销售模式和国家销售统计定义须单独核对。

跨主题例：签约与收入存在履约周期，用户注册与付费存在正常漏斗，产能与产量存在合理备用；不能只把两者不相等当洞察。应研究履约积压是否异常、同群转化是否变差、利用率是否低于适用基线及其经济影响。

图形必须服从审题结果：没有实测库存与基线，就不能画实测库存超标、具体企业跌入风险区或有数值的库存分解。可以做明确标注为分析建议的判别图，说明什么证据支持哪类行动，但不可暗示条件组合是充分因果关系。来源风险判断保留归属，不能升级为本报告已验证的结果。

建议本身也要接受商业合理性检查。不要凭空把多个警示信号变成必须同时满足的行动门槛；没有依据不能声称必须等到价格、利润或客户体验恶化才能预防性调整。区别“影响决策的几个维度”“该建议的一种适用情形”和“必要/充分条件”；原文的若干参考维度不能自动画成交集或固定步骤。来源未提供阈值时，以需求、补货约束与行动成本解释判断，保留其他可能选择。

有业务量纲时优先直接表现被比较的业务对象和适用基线；不能为了凑图形论证把所有题目改写为两个大圆的交集。没有量化数据可选清楚标明的概念示意，但不伪造实测几何或逻辑门槛。

纠正常识型选题后，也不能退化为任何行业都能套用的管理清单。材料已有具体研究线索时，保留一条带来源归属的当期观察或判断，说明为什么现在值得核查；再连接业务基线与行动。无需强选大数字，但不能只留下“先核查再决定”而抹去研究内容。
