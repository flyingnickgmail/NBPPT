# 问题先于图形 · 网页生成与复核共用规则

先在选图判断中明确：读者问题 → 数据条件 → 可见关系 → 最简单的有效图 → 有必要时组合。材料中提到“增长/机制/风险/战略”不是图种指令。最终仅输出当前 schema 支持的图种，配方目录里的储备图不表示已有渲染器。

## 选择与组合

- 大小差异：有序点图/条图；两期同口径变化：哑铃；排名变化：斜率/排名线，必须拥有各期排名；数量与收益共同位置：直接标注散点，不能从行业名称推测坐标。
- 精确增减能闭合：增减桥；只有期末结果而没有贡献分解，保留比较图，不能把差额自动写成原因。
- 多市场走势：同尺度小多图；规模不同但要比较增速时，只有基期有效且计算可追溯才指数化。当前协议不能记录转换依据时保留原值，不暗算指数。
- 平均值掩盖差异：需要逐条样本或真实分位数，才用分布图/箱线/蜂群；只有几个地区均值不能伪装成样本分布。
- 量化风险：带区间点图需要真实上下界、区间含义与覆盖水平；情景集合不等于概率分布。没有概率证据不画扇形置信带。
- 留存/转化：同一批次、分母、观察窗口明确才可计算；只有“出口”和“海外销售”的同比，不能相减得到库存率或画漏斗。
- 定性关系：同维度差异用对照，分类归属用点阵，范围约束用包含，结构原理用剖面/同位对照。无序条件不能排成流程。未提及不是明确不具备。
- 原值很多且口径混合时允许表格。只有两项可比数据时允许简单图，不为新颖加无关维度。

每节先选一个主图回答核心问题；需要组合时用主图加一个不同子问题的辅图，通常不超过三幅。例：毛利变化用增减桥，门店差异用分布，异常门店再列证据；不把同一组值重复画三次。主辅图共同高亮须基于真实对象标识，不把两个无关联数据表强行联接。

## 友车科技研报视觉

暖纸白 #F5F1E9、石墨黑 #252824、铜橙 #B45F36。铜橙只突出本图关注对象；对照用石墨/灰，必要的第二语义色可用低饱和绿灰，并直接标注，避免仅靠颜色辨识。

结论标题 → 对象/期间/单位 → 图形 → 一至两个关键注释 → 来源/必要限定。使用衬线标题、清晰中文正文、等宽数字；无需每条线都加框。图内文字、坐标和标签不倾斜，不以缩字解决重叠；减少次要标注、留出标注区或分面。

网格比数据轻；零线、目标或中位线只有业务含义才保留。条形长度从零开始。散点/折线可局部范围但必须明确刻度，不能以截断制造夸张变化。面积用面积而非半径编码；三维透视和纹理不能改变读数。预测、估计和观察的区别放在读者能看到的位置。

## 叙事动效

先呈现坐标/基准，再出现证据标记，最后强调关键差距。默认一次 400—900ms，支持重播；这是本产品的节奏建议，不是媒体公布标准。滚动只改变强调，不重算值或隐藏关键反例。悬停/点击给原值和来源；键盘可访问。减少动态偏好、打印、静态导出均显示完整最终状态。

用顺序揭示帮助阅读，而非弹跳、循环漂移或数字乱滚。没有连续时间证据时，两点之间的动画不是过程还原，不能演成已观测路径。

## 验收问题

遮住解释段落后，图是否仍能看出所述差异？换掉标题是否能无改动套到任何主题？关键数字、近似词、单位、统计期和来源是否一起保留？手机宽度下是否仍能辨认主结论？若答案不好，先改选图和信息量，再改装饰。

## 限定数值比较（已接入网页）
qualified_dot 用于同单位同期间的可比报告值和限定值，字段 unit、basis、points。每点 label/value/quote/source_ids、relation(exact/approx/gt/lt/gte/lte)、qualifier_quote、emphasis。value保留原数字，下降可用负值；qualifier_quote是quote中含当前数字及限定词的连续短语，且只含这一数值，例如“more than 120%”“down nearly 20%”“75%”。关系词必须靠近数字；负数界限要反向（下降超过20% → lt -20）。approx用近似符号；gt/lt表示开口界限，不声称误差长度。各点共享尺度但可能各有基期分母，basis解释可比范围。不能把翻倍强换算为100，不对界限求精确差值或排序；不支持的词义保留原值表。
comparison允许一组同口径两期端点；不要为凑两行加入异口径指标。所有预测与已发生结果仍分开。

### 编辑式读图节奏（2.9）
共同尺度先稳定出现，再从真实零点展开数据标记，最后显现直接读数。动画结束不改数据位置；约数和界限不动画成假精确数字。每幅图允许“重播读图”一次性重看，尊重系统减少动态效果及打印；不循环闪烁。定性表格不模拟数字增长。数据行减少表格横线，零线比辅助线更清楚；颜色突出关键对象，文字与数据标记紧邻。
