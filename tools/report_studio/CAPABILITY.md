# 可复用的交互报告能力

v0.27 正文生成和复审读取 [商业研究图形表达技能](skills/business-visual-storytelling/SKILL.md) 的问法映射与图表规则；全景图规划、生成、复核读取同一技能的 [内容图标准2.7](skills/business-visual-storytelling/references/cover-standard.md)。模型可选注释式结构对照，保留 c8e7 版本的编辑插画风格；不再强制所有主题画集合图。逐字依据、图形论证、版本绑定和数值检查仍保留。

技能的18项配方中8项映射现有正文图种，9项为待扩展的数据图，另1项为分享图结构表达。储备配方不会进入当前正文模型的可用图种列表；[图形词典](http://127.0.0.1:8766/static/design-atlas.html) 的8幅合成样张只展示表达方法，不是经营数据或全量渲染器上线证明。

概览中的一条综合判断可引用最多三段连续原文，跨章节引文各自携带章节索引，不将分散依据拼成一段。失败任务的设计只能作为草稿恢复，须重新通过引文检查和模型复核；不会直接作为已批准设计进入生图。网页“继续复审与编排”完成正文与读图后即可查看，独立全景图操作负责分享封面，不再重复调用旧封面设计。

这份能力处理“已有材料 → 有依据的分析与信息设计 → 可交互报告”。汽车经营、宏观政策、行业对标、项目复盘等材料均走同一套入口；不是长城汽车专用页面。当前不会自行搜索、解析 PDF 或证明企业数据真实。

## 下次如何使用

v0.13 默认视觉路径：材料 → 已核查的事实目录 → 模型选择核心问题与证据关系 → 引用原始读数的封面 → 按数据形状绘图与有限动效。封面只选已有事实引用，不能自行填写数字；未登记引用、重复引用和新说明中的材料外数字会被拒绝。文字含义、统计可比性仍需编辑审查。

重新设计已有报告：`python -m tools.report_studio.cli design 报告.json --output 新目录`。默认生成证据封面；只有显式 `--style spatial` 才调用原立体构图器。正文、来源、原始数值均保留。`--feedback` 可输入实际审查意见。

单序列分类比较默认共享横轴的细杆端点图；多序列分类比较用统一纵轴和零轴的分组柱图，预测/目标为空心虚线。趋势图仍要求真实有序时间，缺期断线。图表进入视口后展开，可点击“重播图形”；数值文字从始至终显示原值。减少动态偏好、打印和缺少动画接口时直接显示静态终态。两到三个类别在手机上自适应，宽矩阵和更多类别保留局部滚动。

直接在本地工作台 <http://127.0.0.1:8766/> 粘贴材料，选择智能编排。建议材料开头说明“给谁看、回答什么问题”，并保留数字的时间、单位、统计口径、来源和建议性质；没有这些信息时，工具应保留缺口，不能自动补造。

助手与批量任务可使用同一个命令入口，无须启动网页服务：

```sh
.venv/bin/python -m tools.report_studio.cli generate 材料.md --output workspace/我的报告
```

输出目录必须是新目录，避免覆盖已有报告。产物为 `report.html`（离线网页）、`report.json`（结构化内容与完整输入）、`quality.json`（检查发现与范围）。已有报告可重新排版或检查，不必重复调用模型：

```sh
.venv/bin/python -m tools.report_studio.cli render workspace/我的报告/report.json --output workspace/我的报告新版排版
.venv/bin/python -m tools.report_studio.cli check workspace/我的报告/report.json --strict
.venv/bin/python -m tools.report_studio.cli refine workspace/我的报告/report.json --output workspace/我的报告内容复审
```

生成与 `refine` 使用现有 Codex(内容生成工具)账户额度；`refine` 复用已有初稿做内容复审；含动态场景的报告会再设计分镜，保持与修订正文一致。`render` 与 `check` 不调用模型。检查退出码：0 为规则检查通过，2 为结构/引文等错误，3 为严格检查发现表达或正文数字待核对项。0 不等于已经人工验收。

## 每次都会执行的流程

1. **内容编排**：模型从材料中组织问题、证据、解释、建议与限制，输出受约束结构；按关系选择矩阵、趋势、目标、路线、散点或市场图。短材料不强凑长报告。
2. **材料检查**：核对逐字引句、数值及符号、来源编号、链接、日期与时间精度。未知保留空缺，目标和规划不作为已实现结果。失败时最多两次指定字段修复，不换成演示数据。
3. **长材料内容复审**：材料不少于12000字符时，检查分析链、遗漏、过强因果、期间口径，以及是否缺少互补证据。复审读取完整既有图表，最多改8处段落/要点、补3张图、替换12张存在具体问题的图；不能改标题、来源、封面指标或删章节。新增及替换图继续接受同样的材料检查；新正文不能加入材料外数值。
4. **统一渲染**：所有材料共用字体、布局、交互、手机样式、来源弹窗和离线导出。矩阵只有明确方向且口径可比时着色；宽时间轴与稀疏路线可切紧凑视图；侧栏从当前章节图表取值，不凭空生成摘要数字。
5. **结果检查**：记录未匹配的标题/摘要/正文数字、缺少章节来源、重复图名、单点柱图、图注中的制作过程用语及长材料分析过短等问题。多图章节数只记入统计，不作为质量门槛。工作台展示待核对项；命令产物保留检查结果，便于继续修改。

生成与必要修复、长材料复审共享660秒预算。超时或无法通过检查就明确报错，不把半成品伪装为完成报告。复审可判断证据不足而不补图，规则发现也可能需要人判断；不会用固定图数、章节数或一个总分冒充内容质量。

## 怎样验收“可复用”

- 换材料仍调用同一 API(程序调用接口)、命令、提示词、内容合同和渲染器，不为新公司手写网页。
- 旧单图内容仍可导入；更换样式与组件后，已有结构化报告可重新渲染。
- 自动检查覆盖通用材料、负值/缺失、口径排除、时间精度、来源、局部修复、内容复审边界及命令产物。虚构样本用于检查组件，实际模型调用另留证据。
- 每个重要能力改动还需浏览器查看实际报告；自动规则与模型复审不保证叙事说服力、视觉审美或事实真伪。跨主题的稳定性要靠更多真实样本继续验证。

实现入口：`models.py` 为内容合同；`planner_prompt.txt` 为初稿规则；`review_prompt.txt` 为复审规则；`evidence.py` 为材料检查；`quality.py` 为结果诊断；`generator.py` 为生成与修复；`static/` 为共用组件。修改规则后运行本目录测试与前端断言，并用保留输入实测，避免靠手工改一个展示页证明能力。

## 非汽车实测与共享设计（2026-10-18）

用美联储2025年6月货币政策报告两部分的49273字符英文主文，实际生成中文研究报告。相同入口经历初稿、修正规则后重生成及局部复审，最终保留11章9图。新增comparison(前后观察对照图)使用统一尺度、各端点独立引句；不能把目标与实际值混成同一组观察。来源与采集范围、实际发现和结果见 [跨主题实测](../../workspace/report-cross-topic/fed-2025-06/VALIDATION.md)。

非汽车封面直接使用报告关键数据；所有主题共用暖白/深色阅读、图号、图注后置及重点章节“结论—证据—分析”布局。修复中英下降幅度及英文句末数值识别，图表数字仍按字面匹配；不自动换算单位。已验证这一政策样本，尚不代表任意主题可稳定无人审核交付。

## 0.6：主题插画与多序列

输入材料 → 模型选择主题、比较关系与证据性质 → 校验每个数据点及分类对齐 → 共享图表/插画渲染 → 内容复审和离线报告。没有美联储专用分支。

- `illustration` 支持 economy / technology / ecology / none；图像只表示主题，来源标明 AI 概念插画。已有汽车封面兼容。素材库见 `static/illustrations/README.md`。
- `multiseries` 支持2—5组、2—24个分类，共用单位和尺度。分组柱图适合两期或分类比较；折线只接受至少三个真实升序年/月，缺期与null缺测均断开。总体与子项不堆叠。
- `observation` 区分统计观测、调查读数、预测和目标，一张图只选一种；`basis`、逐组`definition`说明统计口径。点标签必须与分类对齐，每点独立引句和来源。程序检查不证明语义可比，仍需复审。
- 图例可筛选但保留至少一组，筛选不改变公共尺度；完整数据表始终可读并可点击查引文。色彩之外用符号、线型区分；手机两期面板纵向排列。
- 旧 JSON 不含新字段时仍可渲染；网页与命令行使用同一导出函数。图片内嵌，离线文件不依赖图库服务。

## 0.7：材料专属场景与随文叙事

长材料的智能生成会在内容复审后，继续从完整材料和已定正文设计3—6个专属矢量对象、证据关系和逐章分镜。对象的几何部件由模型输出，主题不限于原有三类静态图片。共享渲染器把这些数据画成可点击的概念插画，章节变化控制聚焦、并置与部件展开；侧栏放大当前对象，手机使用可展开的底部随文面板。位置、尺寸、动效不编码统计数值。

已有报告可单独升级场景，保留正文、指标和图表：

```sh
.venv/bin/python -m tools.report_studio.cli animate 已有报告/report.json --output workspace/动态报告
```

`animate`调用模型，共享300秒设计/修复预算；新长报告共用660秒预算。少于12000字符的材料不会默认追加场景，可以显式使用`animate`。每章必须有且仅有一帧，对象、关系、旁注绑定连续原句和既有来源；支持一次失败修复，仍不合法则报错。输出仅限几何数据、文案和来源，不执行模型提供的HTML/JavaScript；旧报告无需新字段也能重排。

封面支持手动预览章节，正文滚动会同步随文场景。手动切换暂时停止随文，点击“恢复随文”回到当前阅读位置；支持暂停动效，并遵循系统减少动态效果设置。对象、关系和分镜均可查看引句；离线网页内嵌场景数据与渲染代码。

这是材料驱动的二维矢量分层动画，不是任意三维建模或视频生成。内容合同、几何规则和引句匹配不能替代对关系语义、画面辨识度与审美的实际检查。新生成仍需预览；本轮以美联储历史材料实测，不宣称所有主题都达到同样质量。

## 0.8：贴题实物、语义部件与表现模式

输入材料与已定正文 → 模型说明物体为什么适合该材料 → 原创轮廓、材质与语义部件组 → 逐章选择焦点和动作 → 引文/结构检查 → 同一渲染器输出报告。没有美联储物体库、题目匹配分支或专用网页。

设计规则优先采用材料讨论的现实对象和读者熟悉的物品；不再要求建筑式造型，也不把所有概念改成虚构机器。每个对象的`rationale`说明材料联系和比喻边界；其`parts`使用受约束几何和统一色板，可选择纸张、金属、玻璃等材质表现。形状仍由模型绘制，材质只是共享渲染方式。

`assemblies`以盖、编织片、掌垫、插页等语义分组，提供有限位移、转角与支点；`beats.actions`选择本章查看哪些组。支持揭示结构、描边观察、小幅角度观察和位移展示。动作不表示真实统计变化。程序拒绝不存在的组、重复动作、作用于非焦点对象、零位移的展开及改变遮挡顺序的交错分组。

默认放大本章主体或并置相关物体，不再把所有对象常驻排成等大的小图标。四种视图共用同一份几何：随文、结构展开、精细线稿、全景。全景提供全部对象证据入口，其他模式保留当前焦点。目录跳转恢复随文；手动预览仍可保留独立章节。动画支持暂停，隐藏视图和后台页面停止循环动画，系统减少动态设置仍优先。旧`classic`场景继续兼容，新生成必须使用`semantic`设计。

证据不匹配复用既有的指定字段修复流程，保持已验证造型和动作不变；结构错误才重新生成整套场景。`animate`命令和长材料自动生成入口不变。预算仍为场景300秒、完整长报告660秒。

本轮美联储实测经历一次审美调整后重新生成，最终选择购物篮、运输箱、工作手套和分栏账册。此结果证明该材料可以通过共享规则获得不同造型，不证明任意新材料首次生成就能达到同样审美。使用前仍应查看实际报告。详见 [实测记录](../../workspace/report-cross-topic/fed-2025-06/VALIDATION.md)。

### v0.9 表达层合同

输入原材料与已核对正文，模型生成 `spatial`（2—5组、12—72部件、逐章旁注），确定性引擎将几何、材质、镜头与标签投影到同一画幅。几何是有界数据，不接收任意代码或外部资源。事实与构图理由分离；图片大小、位移和动作不测量统计值。`design --feedback` 可将实际视觉问题纳入下一轮，保留原输出与正文。

选图在两处生效：正文规划阶段获得数据形状规则；导出阶段用 `recommend_design` 读取已校验数据，生成不可变的渲染配方及 `design.json`。端点与趋势的区别、空缺、统一尺度及预测/目标状态必须保持。时间轴目前精确趋势支持同粒度 YYYY 或 YYYY-MM；季度等以离散比较保留，不假装连续曲线。

该阶段材质为程序化近似光照。旧 `story`、`spatial` 报告保持兼容；v0.13 起新长材料默认使用下述证据封面，不再强制三维物件。

### v0.10 视觉决策与有限开场

输入仍为完整材料和已经核对的正文。模型先比较三种视觉路线，记录中心问题、候选关联、误读风险和选择理由，再输出受约束的几何及分组出场顺序。关系型主题不再强制套真实物品；具体产品主题仍可使用直接造型。真实数据图与概念构图分开，几何大小和运动不充当统计编码。

新增 `rounded_box`、`lathe`、`arc`：旋转曲面节点为严格递增高度与非负半径，弧环角度为30–360度。输入继续拒绝任意代码、图片及外部资源。开场使用纯时间函数决定淡入、位移和收束；只有播放开场时持续绘制，完成/暂停/离屏后停止自动更新。章节改变继续更新聚焦与引文，不重播开场。旧场景兼容。

品牌配置独立于模型与正文。当前铜橙试用主题经用户授权，可替换为友车科技正式规范；不在模型提示词或每张图表硬编码主题数据。边界：几何和引文检查不能自动判定图是否贴题、美观；仍需实际浏览器审查，给出反馈后重新设计。

### v0.11 图表读数与跨材料视觉选择

输入新的长材料 → 内容模型按口径选择图表 → 视觉模型独立比较直接对象、关系构图和编辑隐喻 → 共享品牌、图表与空间渲染 → 引文检查、内容复审和浏览器验收。

- `static/charts.css` 统一细网格、明确基线、直接读数、紧凑排名条和账本式矩阵；随品牌配置切换浅深色。
- 多序列端点标签自动避让，以细引线回到真实观察位置；不改变数值、点位、缺测或尺度。小多图在相同坐标范围内比较，预测/目标继续采用虚线空心语义。
- 视觉选择取消默认偏好曲面的提示，要求说明材料中的具体对象或关系如何决定造型，并检查换行业后是否仍可原样套用；不提供本轮报告专用物件模板。
- 空间旋转统一使用度，提示词与结构约束一致；引文检查识别英文下降表达和空格千分位，同时拒绝将“下降到某值”误判为负数或拆开千位数字。
- 这些规则改善生成与呈现，不能替代内容和审美审查。实际新主题运行及修正范围见 VALIDATION.md。

### v0.12 连续外壳、深度与材质

同一份已审核内容 → 模型按真实物体比例设计主体、结构分界和小面积功能细节 → 通用截面外壳与材质引擎绘制 → 按语义分组逐步出场 → 保留原数据与引文的新版报告。

- `loft`（连续截面外壳）描述产品壳体、机身或流线轮廓；有界截面插值不越出模型提供的包围范围，拒绝倒序、零宽和倒置截面。它没有内置汽车模板。
- `space_gpu.js` 使用固定的 WebGL（浏览器三维绘制）程序做逐像素深度判断和法线平滑，避免多个曲面相交时的平均深度排序伪影。模型不能提供着色代码。保留硬边；金属、暗玻璃、纸、橡胶分别使用反射参数。材质为程序化近似，不是物理精确渲染。
- 无三维绘制能力或丢失绘制上下文时，继续使用原矢量绘制；工程线稿也走矢量路径。降级情况下复杂交叠的遮挡精度有限。正文、图表和来源不依赖三维绘制。
- 开场让主体先出现、短标签随后出现，轻微镜头收束后停止；地面阴影跟随语义对象。暂停、减少动态与随文聚焦保留，不循环漂浮。
- 共享图表进一步采用分类标题、细线图例、直接数值和统一尺度；跨零坐标的正百分比显式标注加号，普通份额不添加增长式符号，不改变值和统计语义。不同单位仍须拆分，禁止通过装饰性缩放制造可比性。

### v0.15 自动组合与叙事引用合同

新长材料默认沿用同一入口：完整输入 → 模型形成带证据的正文与图表 → 受限复审 → 模型选择重点问题、2—4个步骤及段落/图表/数据项引用 → 编辑封面 → 共享渲染。初稿、复审和读图设计均由模型完成；导出阶段只决定尺度、排版和交互，不替模型补写业务数据。

- `waterfall`：起点、原始有符号增减项、终点、统一单位与统计口径；按十进制数检查闭合，不允许自动补残差。当前不支持从正数税费自动推导负向贡献，需材料本身支持输入符号或采用已披露净额。
- `mechanism`：最多3条泳道、4个阶段、8个节点、10条关系；节点与关系均绑定原句。阶段仅表达顺序，箭头不表示量化因果强度，状态用文字和线型共同区分。
- `reading`：问题、选择理由、2—4步；每步只能引用本节已有图表、数据项和正文。引用越界和新增材料外数字被拒绝。排序或图表重绘后保留原数据身份；用户手动选择优先于正文滚动。
- 图表入场、重播、系统减少动态与打印回退继续共用。打印展开全部图形；手机宽图局部横向滚动，并保留完整证据列表。

不因“专业”而强加图种。桑基图需要真实流量，漏斗需要同一批对象的阶段转化，评分矩阵需要明确评分依据；缺失时选证据关系图、对照或表格。专业图的判断标准是问题是否被解释、尺度是否诚实、读者是否容易核对。

当前检查无法证明语义因果、跨指标可比性或审美达标，仍需要实际预览。v0.15完整长材料预算上限1800秒，取代前述历史版本预算；模型服务慢时仍可能失败。

### v0.17 网页自动全景图

独立报告或工作台点击“一键生成全景图” → 全文主线与事实目录交给设计模型 → 校验逐字引文及原始数值 → 实际图片工具生成 → 附图交给模型复核 → 同版本报告嵌入并支持下载。生成任务保存在本地；无需手写单份材料提示词。

- 设计模型分配主题、构图、正文、已披露/建议/未知状态；绘图阶段不自行添加结论或假设问题。禁止在纸页和屏幕插画里塞入没有数据的柱形/折线，也禁止疑问句预设未披露的收益已经实现。
- 完整检查实际图片的负号、单位、期间和结论边界；最多一次复核驱动的重画。模型复核仍可能漏错，分享前保留人工核阅入口与说明。
- 重复点击、轮询断线及完成结果读取失败均接回原任务；换报告不接旧任务。重启后已完成结果可恢复，未完成任务明确报错。原报告始终保留。
- 本机与离线报告均可放大和下载 PNG；离线文件不提供生图按钮。完整运行资料在 `workspace/report-overviews/<job-id>/`。

### v0.18 按解释问题选择全景构图

全文与证据 → 模型比较三个信息结构不同的方案 → 选出能解释材料关系且适合手机的方案 → 仅把选中方案交给图片工具 → 检查关系是否真的出现在图上，按复核意见局部修图。

- `selection` 保存候选构图的表达方式、材料依据、误读风险和选择理由，不只记录物件名称。旧设计可继续读取；新设计必须比较候选。通用物件只能辅助，不能代替主要关系。
- 机制材料允许不选大数字；正文优先保留约200字的主要判断，详细证据留在正文。图文复核检查手机缩小后的层级和关系表达，仍需实际预览。
- 来源作者或反馈者的方案用“来源建议”，本报告推论用“分析建议”，不把反馈汇编包装成已生效标准或企业部署成果。
- 生产模型选择精确结构绘图或场景插画。结构方式支持请求、无箭头关联、阻断真实请求入口、单层范围包含和整体状态边界，所有角色及关系绑定正文引句。程序排印中文并绕开无关节点，不执行模型代码。最多12节点、16关系、3列4层，分享短要点与原panel对应。
- 图文复核后，结构方式修订结构再绘制，插画方式编辑原图；不同生产方式使用同一个网页入口。模型复核和结构检查仍需实际手机预览补充。
